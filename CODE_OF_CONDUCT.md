# Contributor Covenant Code of Conduct

We are committed to providing a welcoming, respectful, and harassment-free experience for everyone contributing to or using MailGate, regardless of experience level, background, or identity.

## Expected Behavior

- Be constructive, empathetic, and direct in code reviews and issue discussions.
- Focus critique on code, architecture, and user impact — never on individuals.
- Respect maintainers' and contributors' time by providing reproducible bug reports and focused pull requests.

## Unacceptable Behavior

- Harassment, personal attacks, trolling, or discriminatory language.
- Publishing private information, personal emails, or secrets without explicit permission.

Project maintainers may remove comments, commits, or issues that violate this Code of Conduct.
